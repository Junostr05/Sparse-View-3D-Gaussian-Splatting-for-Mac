# Phase 1 — Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Per `CLAUDE.md`: workers never commit — they return their diff; the orchestrator reviews and commits.

**Goal:** A document-based macOS app ("SparseSplat", working name) that opens 3DGS `.ply` and `.splat` files and renders them smoothly with a tile-based Metal compute rasterizer and an orbit camera.

**Architecture:** Pure-Swift `SplatCore` (math, camera, Gaussian data, CPU reference rasterizer) and `SplatIO` (file readers) build and test on Linux and macOS. `SplatMetal` (prefix sum, radix sort, forward tile rasterizer) is macOS-only and is tested against the CPU reference. The SwiftUI app is generated by XcodeGen and hosts an `MTKView` that redraws on demand. The forward rasterizer is the one Phase 2 will extend with a backward pass, so its math follows gsplat conventions exactly.

**Tech Stack:** Swift 6.2, Swift Testing, Metal (runtime-compiled shaders), SwiftUI + AppKit bridge, XcodeGen, GitHub Actions.

**Spec:** `docs/ARCHITECTURE.md` (decisions 1, 8–13, 15–17; Phase 1).

## Global Constraints

- Deployment target macOS 26 (`.macOS(.v26)`); macOS 27 APIs only behind `#available(macOS 27, *)`.
- `swift-tools-version: 6.2`, Swift 6 language mode, strict concurrency.
- Library modules (`SplatCore`, `SplatIO`, `SplatMetal`) use **default (nonisolated) isolation**. Only the app target uses `@MainActor` default isolation.
- `SplatCore` and `SplatIO` import only Swift stdlib + `Foundation` (no `simd`, no Apple-only frameworks) so they compile on Linux. Vectors use stdlib `SIMD2/3/4<Float>`.
- No third-party dependencies. XcodeGen is a dev tool, not a dependency.
- Package lives in `SplatKit/` (not `Packages/`, which is git-ignored). App sources in `App/`. `project.yml` at repo root; `*.xcodeproj` is never committed.
- Bundle identifier `io.github.junostr05.SparseSplat`; product name `SparseSplat`.
- Never port code from `graphdeco-inria/gaussian-splatting`. Math follows gsplat (Apache-2.0) conventions as specified below.
- Structs shared between Swift and MSL contain only `Float`, `UInt32`, `Int32` and `SIMD4<Float>` fields (no `SIMD3`, whose size/alignment differs).
- Shaders are compiled with `MTLCompileOptions.mathMode = .safe` so GPU output matches the CPU reference.
- Liquid Glass: viewport is content layer (no glass). Use system toolbar and `.inspector` only — no custom `glassEffect` in Phase 1.

## Review Focus

1. **PLY files with extra or reordered properties** (normals `nx/ny/nz`, `double` fields, `f_rest` before `opacity`) must load correctly — Task 2 test `readsReorderedAndExtraProperties`.
2. **Non-finite values (NaN/Inf) in a file** must be dropped and counted, never reach the GPU — Task 1 test `removingNonFiniteDropsBadGaussians`, Task 3 test `sceneLoaderReportsRemovedCount`.
3. **Gaussians behind or at the camera / camera inside the scene** must be culled without NaN pixels — Task 4 test `gaussianBehindCameraIsCulled`, Task 6 test `noVisibleGaussiansRendersBackground`.
4. **Viewport sizes that are not multiples of 16, and 1×1** must render edge pixels correctly — Task 6 test `matchesCPUReferenceOnOddSize`, Task 7 skips 0-sized drawables.
5. **Zero visible Gaussians** (camera looking away) must render the background without creating zero-length Metal buffers (`makeBuffer(length: 0)` returns nil) — Task 6 test `noVisibleGaussiansRendersBackground`.

## Shared math (referenced by Tasks 4 and 6)

All values follow gsplat's classic (non-antialiased) 3DGS forward pass.

- Activations: `scale = exp(logScale)`, `opacity = 1 / (1 + exp(-logit))`, quaternion `q = (w, x, y, z)` normalized, zero quaternion → identity.
- Camera: OpenCV convention (x right, y down, z forward); `p_cam = R · p_world + t`; camera center `C = -Rᵀ t`.
- Cull if `z_cam < nearPlane (0.01)` or `z_cam > farPlane (1e10)`.
- `mean2D = (fx · x/z + cx, fy · y/z + cy)`.
- `Σ3D = R_q · diag(scale²) · R_qᵀ`. Jacobian with clamping: `tanFovX = 0.5·W/fx`, `limXPos = (W − cx)/fx + 0.3·tanFovX`, `limXNeg = cx/fx + 0.3·tanFovX` (same for y with H, cy, fy); `tx = z · clamp(x/z, −limXNeg, limXPos)`, `ty` likewise. `J = [[fx/z, 0, −fx·tx/z²], [0, fy/z, −fy·ty/z²]]`. `Σ2D = J · R · Σ3D · Rᵀ · Jᵀ`, then add `eps2D = 0.3` to both diagonal entries.
- `a, b, c = Σ2D[0,0], Σ2D[0,1], Σ2D[1,1]`; `det = a·c − b²`; cull if `det <= 0`. `conic = (c/det, −b/det, a/det)`.
- Radius: `mid = 0.5·(a + c)`, `λ = mid + sqrt(max(0.1, mid² − det))`, `radius = ceil(3 · sqrt(λ))`; cull if `radius <= 0`.
- Tile rect (tileSize 16, integer truncation, `tilesX = ceil(W/16)`): `minX = clamp(Int((mean.x − r)/16), 0, tilesX)`, `maxX = clamp(Int((mean.x + r + 15)/16), 0, tilesX)` (exclusive); same for y. Cull if the rect is empty.
- Color: `dir = normalize(p_world − C)`; `color = max(SH(dir) + 0.5, 0)` per channel, evaluated up to `min(shDegree, shDegreeLimit)`.
- SH layout in `GaussianCloud.sh`: `[gaussian][coefficient k][channel c]`, `K = (degree+1)²`, k = 0 is DC. With `(x, y, z) = dir`:
  - deg 0: `C0·sh0`, `C0 = 0.28209479177387814`
  - deg 1: `+ C1·(−y·sh1 + z·sh2 − x·sh3)`, `C1 = 0.4886025119029199`
  - deg 2: `xx, yy, zz, xy, yz, xz`; `+ C2₀·xy·sh4 + C2₁·yz·sh5 + C2₂·(2zz − xx − yy)·sh6 + C2₃·xz·sh7 + C2₄·(xx − yy)·sh8`, `C2 = [1.0925484305920792, −1.0925484305920792, 0.31539156525252005, −1.0925484305920792, 0.5462742152960396]`
  - deg 3: `+ C3₀·y(3xx − yy)·sh9 + C3₁·xy·z·sh10 + C3₂·y(4zz − xx − yy)·sh11 + C3₃·z(2zz − 3xx − 3yy)·sh12 + C3₄·x(4zz − xx − yy)·sh13 + C3₅·z(xx − yy)·sh14 + C3₆·x(xx − 3yy)·sh15`, `C3 = [−0.5900435899266435, 2.890611442640554, −0.4570457994644658, 0.3731763325901154, −0.4570457994644658, 1.445305721320277, −0.5900435899266435]`
- Per-tile order: ascending camera depth `z`, ties by ascending Gaussian index (stable sort).
- Pixel `(x, y)` has center `p = (x + 0.5, y + 0.5)`. Front to back with `T = 1`: `d = mean2D − p`; `σ = 0.5·(conic.x·dx² + conic.z·dy²) + conic.y·dx·dy`; skip if `σ < 0`; `α = min(0.999, opacity·exp(−σ))`; skip if `α < 1/255`; `nextT = T·(1 − α)`; if `nextT <= 1e-4` stop **before** blending this Gaussian; `rgb += color·α·T`; `T = nextT`. Output `rgb + T·background`.
- A Gaussian contributes to a pixel only if the pixel's tile lies inside the Gaussian's tile rect.

Pipeline per frame: command buffer A — project (one thread per Gaussian, writes `ProjectedGaussian`-equivalent buffers + tiles touched) → exclusive scan; wait; read total intersections.
