Depth Anything V2 Small

downloaded by the appApache-2.049 MBCore ML Float16

Monocular depth for the depth prior. The app downloads it on first use and verifies its checksums, so you normally do not need to do anything. The files are Apple's Core ML conversion, pinned to one commit.

Depth Anything 3 Base (pose-free)

Apache-2.0583 MBCore ML int8manual import

Estimates depth and camera poses without a calibrated camera. SparseSplat uses it as a fallback when Apple Photogrammetry cannot register the photos. It is less accurate than Apple Photogrammetry (about 0.8 dB lower PSNR on the reference scene).

Not published yet

  1. Download the folder DepthAnything3BaseQ8.mlpackage.
  2. In SparseSplat open a project, then Pose-Free Model → Import Package… and choose the folder.
